# HIX v2.3.11

**Date:** 2026-10-06
**Base:** v2.3.10 (resources/dll relocation)

## What was achieved

Split `examples/wdo/` into one self-contained HIX project per driver, so
users only need to install the runtime dependencies of the drivers they
actually want to run. SQLite3 needs no external DLL at all; MySQL
needs `libmysql64.dll` (or `libmariadb64.dll`) only in its own
subfolder.

## Layout

Before:

```
examples/wdo/
├── app.exe              # single binary, both drivers
├── www/
│   ├── config.json      # declared BOTH mysql + sqlite pools
│   ├── mysql/mysqlN.html
│   └── sqlite3/sqliteN.html
└── (3 HIX DLLs + optional libmysql64.dll)
```

After:

```
examples/wdo/
├── readme.md            # index to subprojects
├── mysql/               # self-contained MySQL demo
│   ├── app.hbp, app.rc, go_*.{bat,sh}, hix.json
│   ├── src/app.prg
│   ├── www/{config.json, index.html, header.html, mysql0..6.html}
│   └── (3 HIX DLLs — libmysql64.dll copied by user)
└── sqlite3/             # self-contained SQLite3 demo
    ├── app.hbp, app.rc, go_*.{bat,sh}, hix.json
    ├── src/app.prg
    ├── www/{config.json, index.html, header.html, sqlite0..6.html, sqlite_debug.html}
    ├── www/data/{demo.db, demo.db-wal, demo.db-shm}
    └── (3 HIX DLLs)
```

Key points:
- Each subproject's `www/` is **flat** (`mysql0.html`, `sqlite0.html`
  live at `www/` root — the driver-name subdir is redundant inside a
  dedicated project).
- `www/config.json` of each subproject declares only its own driver
  under `databases.*`. No MySQL dependency when running SQLite3, and
  viceversa.
- Both subprojects default to `port 8081` — run them one at a time
  (or edit `hix.json` to pick different ports).
- `src/app.prg` is **duplicated** per subproject (10 trivial lines;
  self-contained examples are easier to copy as starting points).
- `go_*.{bat,sh}` scripts up `..\..\..` (one level deeper than before)
  to still resolve `${hix}` to the repo root.

## MySQL runtime DLLs — where they live

The repo ships both `libmysql64.dll` and `libmariadb64.dll` under
`resources/wdo/mysql/dll/`. Users of the MySQL subproject copy
whichever one matches their server next to `examples/wdo/mysql/app.exe`
before running. The SQLite3 subproject needs nothing extra.

## Verification

- `tests/wdo/test_wdo_sqlite3`: 31/31 pass (unchanged — this release
  only reorganizes the example, not the driver).
- `examples/wdo/sqlite3/app.exe` smoke-tested: `/index.html`,
  `/sqlite2.html` → HTTP 200 x2 (no DB lock after error path).
- `examples/wdo/mysql/app.exe` built OK; hard-fails cleanly with
  `==> Error: Mysql not running (127.0.0.1:3306)` on a machine without
  a running MySQL — confirming the v2.3.05 preflight path works
  identically in the new layout.

## Not touched

- `src/wdo/**` driver code
- `hix_server.lib` / `.hbx`
- Tests under `tests/wdo/`

Pure reorganization of the example project.
