# HIX v2.2.1 — Independent Audit Remediation

**Date:** 2026-09-23
**Base:** v2.2 (Audit Edition)
**Source audit:** `docs/auditoria.2/2026-09-22_analisis_independiente.md`

## What was achieved

Closure of every actionable finding from the second, independent audit
run against `main` post-v2.2. Fourteen of fifteen items shipped as fixes
with regression tests; the remaining one (**W5** — WSS workers coming
from the HTTP pool) is a design decision explicitly deferred.

Test suite: **2155 total — 2155 passed — 0 failed**.

Verdict table: `docs/auditoria.2/2026-09-23_veredictos_analisis_independiente.md`.

---

## Distribution by area

| Area | Items closed | Highlights |
|---|---:|---|
| **Routing** (R1–R5) | 5 | atomic route reload, `Respond` double-call guard, SSE per-conn mutex, `INIT PROCEDURE` for lazy mutexes |
| **Sessions** (S1–S4) | 4 | hash isolated per context (clone-on-read/write), file store atomic write with per-SID bucket mutex, GC re-checks HMAC before deleting, init procedure for store |
| **WebSocket** (W1–W6) | 5 | control frames under `oConn:oMutex`, per-SSL* mutex serializing Read/Write/Close, 4 GB frame length (code 127), ping_interval/ping_timeout from config, continuation frames (opcode 0x00) reassembled with strict RFC 6455 §5.4 state machine |
| **Config** (A1.15/16) | 1 | session key fallback removed → fail-hard on missing configuration |

## Deferred

**W5** (WSS handshake occupies HTTP pool workers) — architectural
limitation, not a bug. Requires a decision on segregating the WS pool
with in-pool SSL handshake. Left open in the verdict table for a future
release cycle.
