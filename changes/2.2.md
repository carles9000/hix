## Changes

### 1. Library purity — zero test symbols in production build

`hix_server.lib` no longer contains any `HIX_Test*` wrapper functions.
All 7 helpers that existed solely to expose internal state to tests have
been removed from the production sources:

| Removed function | Source file |
|---|---|
| `HIX_TestAdminSign` | `src/hix_admin.prg` |
| `HIX_TestPublicFallback` | `src/hix_dispatcher.prg` |
| `HIX_TestLoaderHashOk` | `src/hix_loader.prg` |
| `HIX_TestJsonBody` | `src/hix_request.prg` |
| `HIX_TestCookieReq` | `src/hix_request.prg` |
| `HIX_SanitizeCookiePart` | `src/hix_request.prg` |
| `HIX_TestValidateMacroExpr` | `src/hix_view_parser.prg` |

`hix_server.hbx` regenerated: `grep HIX_Test = 0 symbols`.

### 2. Black-box test rewrites

Every test that previously called a `HIX_Test*` wrapper was rewritten
to exercise only the public API or inline the minimal logic needed:

- **A03302 / A03303 / A03305** — construct `THixRequest():New()` directly,
  assign `cBody` / `hHeaders["cookie"]` and call the public parse methods.
- **A03304** — call `HIX_SetCookie(oReq, "test", cRaw, 0)` and inspect
  `oReq:hExtraHeaders["Set-Cookie"]` for injected characters.
- **A03307** — instantiate `HIX_Parser():New()` and call
  `ValidateMacroExpr()` directly.
- **A03404** — inline `Lower(hb_HMAC_SHA256(hb_NToS(nTs), cSecret))`.
- **A03406** — inline MD5 + file existence check for loader hash
  validation.
- **A03106** — replaced a live HTTP server (which mutated global config
  and caused 403s on the web UI) with a STATIC function `_A03106_Fallback`
  that replicates `_HixTryPublicFallback` logic in the test binary only.

### 3. Global config isolation fix

The A3.1.6 test previously spun up a `THixServer` instance and set
`HIX_GetConfig()["hixstyle"]["enabled"] := .T.`.  Because `HIX_GetConfig()`
returns a reference to the shared global hash, running tests from the
web UI (same process as the server) activated the hixstyle ACL whitelist
and returned 403 for `/js/app.js` and `/img/hix.ico`.

The new inline approach uses no server, no config mutation, and no ports.

### 4. Test dashboard improvements

- **Sticky header**: navbar + progress bar stay visible while scrolling
  through long test tables.
- **OS badge** (purple): shows `Windows`, `Linux`, or `macOS` — populated
  from the `/server-info` endpoint alongside the existing compiler badge.
- **Fixed footer**: copyright bar pinned to the bottom of the viewport,
  text right-aligned (`© 2026 - Charly`).
