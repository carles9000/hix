## Highlights by domain

### Security (Section 1 — URGENT)

- **A1.01** — RCE via macro `&()` in the router. Fix: string-action
  whitelist; only pre-registered function names are dispatchable.
- **A1.02 / A1.03 / A1.04** — Path traversal: URL-encoded `%2e%2e`,
  symlink/junction escape, and multipart `filename="../..."` all
  hardened at the dispatcher and upload paths.
- **A1.07-A1.10** — JWT hardening: constant-time signature check,
  explicit `alg=none` rejection, `iss / aud / iat / leeway` binding.
- **A1.11 / A1.12** — CSPRNG for session IDs and token generator
  (replaces `hb_Random` / `hb_RandomInt`).
- **A1.13 / A1.14** — Trust list for proxy IPs — X-Forwarded-For is
  no longer trusted blindly (fixes rate-limit and anomaly detector
  bypass by header spoofing).
- **A1.15 / A1.16** — Admin panel no longer enabled by default
  without credentials; hardcoded JWT/session defaults removed.
- **A1.17** — ReDoS: user-supplied `validator:regex:...` now runs
  through a length + timeout guard.
- **A1.18** — Session file storage: deserialization guard, Blowfish
  ECB replaced with authenticated encryption, tightened file perms.
- **A1.19 / A1.20** — Session fixation prevented (SID rotation on
  login) and file GC TOCTOU race closed.
- **A1.21** — XSS in default error page removed (`HTML_encode` on
  message body).
- **A1.22 / A1.23 / A1.24** — Slowloris via total header-read budget,
  `HIX_MAX_BODY_SIZE` enforced pre-read (413), JSON recursion limit.
- **A1.25** — Route regex escaping — `.` in `/v1.0/data` no longer
  behaves as a wildcard.
- **A1.26** — HRB thread timeout race: `hb_threadJoin` on the normal
  path and `hb_threadDetach` on the timeout path eliminate the
  handle leak; zombie registry decoupled from OS thread handles.
- **A1.27 / A1.28** — View transpiler: macro-eval `&()` removed from
  `{{ }}` validator; `{!! !!}` raw output kept intentional, `UHtmlEncode`
  verified against edge cases.

### Concurrency (Section 2 — URGENT)

- **A2.01 / A2.06** — All STATIC globals in server, router, and
  worker paths now protected by mutex or double-checked lazy init.
- **A2.02** — Accept loop shutdown made non-blocking with poll
  timeout + graceful pool drain.
- **A2.03 / A2.05** — `THixWsConn:Send`/`SendBinary` synchronised
  with the connection's mutex; lazy mutex init race closed.
- **A2.04** — WebSocket callbacks now wrapped in `TRY / CATCH`.
- **A2.07 / A2.08** — Sequence counters and logger rotation moved
  inside the mutex; unlock guaranteed via exception safety.
- **A2.09** — DBF work-area alias collision between threads fixed:
  aliases now carry a 6-hex thread-id prefix.
- **A2.10** — Thread-local context reset via TRY / FINALLY on worker
  exit paths.
- **A2.11** — Pre-read body buffer now counted against `Content-Length`
  bound; early check in the worker.
- **A2.12** — `hb_mutexSubscribe` timeout floor 1 ms — protects
  dispatcher and long-poll from `nMs = 0` deadlocks.
- **A2.13** — `Write()` EAGAIN retry now sleeps 1 ms between attempts.

### Bugs (Section 3 — MAJOR)

- **Routing / dispatcher** (7 items) — `$` substring match replaced
  by `==` in method comparison; 404 / 405 handlers now build a minimal
  `THixContext`; hello-page no longer shadows the 404 handler;
  path normalisation deduplicated between router and dispatcher.
- **Middleware / security** (4 items) — CORS wildcard + Authorization
  warning; IPv6 firewall handles scope IDs; rate-limit sliding
  window; anomaly-detector STATIC race.
- **Request / response / views** (8 items) — JSON parse error no
  longer masked as empty body; RFC 6265 cookie parser; `Set-Cookie`
  injection sanitised; cookie names now case-insensitive; `%00` in
  URL decode dropped; macro-expr cache propagates errors; `ReplaceVars`
  escapes regex metacharacters in `@args` names.
- **Config / loaders / data** (11 items) — `HIX_LoadConfig` respects
  `cFile` argument; corrupt `hix.json` warning; admin password now
  HMAC with per-install salt; admin cookie HMAC-signed; loader
  hot-reload mutex; HRB invalidation by MD5+mtime; cycle detection
  in dependency resolver; pool lock timeout + max size; DBF `Update`
  TRY / FINALLY + RLock spinlock sleep.
- **Helpers / errors** (2 items) — `HIX_Metric:Inc()` uses
  `hb_HGetDef` to avoid a micro-race; `HIX_ConstantEq` early-exit
  on length mismatch.

### Fragility (Section 4 — REGULAR)

- **A4.01 / A4.02** — Dispatcher refactor: `_CheckACL`,
  `_ResolveIndex`, `_ServeStaticFile` extracted; commented dead code
  removed.
- **A4.03** — Router: `_HGet` linear scan replaced by
  `HB_HCaseMatch + hb_HGetDef`.
- **A4.04** — `RespondChunk` capped at `HIX_CHUNK_SIZE` (64 KB).
- **A4.05** — `HIX_MAX_DIRECTIVE_DEPTH = 64` in view parser.
- **A4.06** — View cache invalidation now by mtime + MD5 (not mtime
  alone) — catches sub-millisecond writes.
- **A4.07** — View transpiler no longer logs generated PRG on error.
- **A4.08** — HTML tag stripper handles attributes with `>`, comments,
  entities correctly.
- **A4.09** — Slug function preserves diacritics (`café → cafe`
  instead of losing the vowel).
- **A4.10** — Bootlog callback invoked outside the mutex — decision
  documented in-source.
- **A4.11** — `HIX_PreambleLines()` computed dynamically — no
  hardcoded offset to drift.
- **A4.12** — Trailing slash: `/users` and `/users/` now dispatch
  to the same route (strip only for match, `oReq:cPath` preserved).
- **A4.13** — `HIX_SetCookie` appends `; Secure` when
  `oReq:IsHttps()` — mandatory over HTTPS to prevent hijacking.
- **A4.14** — `HIX_ConstantEq` shared helper extracted to
  `hix_helpers.prg`; the duplicated `_HixConstantEq` (jwt) and
  `_HixTokenConstantEq` (token) now delegate.

## New constants / public API surface

- `HIX_MAX_BODY_SIZE`, `HIX_MAX_JSON_DEPTH`, `HIX_MAX_DIRECTIVE_DEPTH`,
  `HIX_HEADER_TOTAL_TIMEOUT`, `HIX_CHUNK_SIZE` — bounds now enforced.
- `HIX_ConstantEq(cA, cB)` — canonical constant-time compare (public).
- `HIX_ZombieAdd / Dead / Purge / Overload / Report` — zombie thread
  registry (already public in prior versions; usage clarified).
- `HIX_TimeoutSec(nMs)` — timeout floor helper (1 ms).
- `HIX_PathNormalize(cPath)` — canonical HTTP path form.
- `UPeerAlive()` — non-destructive peek used in SSE controllers.

## Future work (out of audit scope)

- Use `HIX_ZombieOverload()` as a circuit-breaker / back-pressure
  gate to reject new requests when the pool of runaway threads
  exceeds a threshold. Harbour offers no thread-kill primitive, so
  this is the correct escape hatch for truly infinite runaway loops.
- Migrate remaining `md5` uses in non-security paths to `hb_hashID`
  for consistency (cosmetic).
