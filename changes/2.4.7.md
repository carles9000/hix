# HIX v2.4.7

**Date:** 2026-11-09
**Base:** v2.4.6
**Type:** Feature

## What was achieved

Primitiva de almacenamiento de claves integrada en el core HIX como
`src/hix_password.prg`. Expone tres funciones públicas sobre
PBKDF2-HMAC-SHA256 via OpenSSL `libcrypto` (resuelto en runtime, la
misma librería que HIX ya carga para HMAC/JWT/CSRF). Sin dependencias
de DBF, request ni sesión — entrada/salida pura, mínimo 600 000
iteraciones por defecto (OWASP 2026).

### API pública

```harbour
HIX_PasswordHash( cPassword [, nRounds ] )   -> { PASSALG, PASSITER, SALT, PASSHASH } | NIL
HIX_PasswordVerify( cPassword, hRecord )     -> .T. | .F.
HIX_PasswordNeedsRehash( hRecord )           -> .T. | .F.
```

- Record portable (DBF o JSON): `PASSALG C(16)`, `PASSITER N(9)`,
  `SALT C(32)`, `PASSHASH C(64)`.
- Comparación en `Verify` vía `HIX_ConstantEq` (timing-safe).
- Salt 16 bytes generado con `RAND_bytes` de libcrypto.
- `NeedsRehash` facilita subir coste en caliente al login sin forzar
  reset de claves.

### Tests

Nuevo test `tests/unit/src/hix_test_password.prg` con 20 assertions:
- Hash shape (algoritmo, iter, salt len, hash len, unicidad por salt).
- Verify sobre clave correcta / incorrecta / record corrupto
  (hash tampered, algoritmo desconocido, salt no-hex, record no-hash).
- NeedsRehash para fresh / NIL / rounds por debajo del mínimo /
  algoritmo obsoleto / salt corto.
- Input validation (clave vacía, NIL, rounds < 600 000 → NIL).

Suite filtrada `app.exe --cli Password`: 26/26 passed.
