## Changes in the library

### A1.22 — Slowloris: total header-read timeout (`src/hix_io.prg`)

`ReadHeaders()` now accepts a second parameter `nTotalTimeout`
(default `HIX_HEADER_TOTAL_TIMEOUT = 10 000 ms`). A deadline is set
at entry; each `Recv` call is capped to
`Min(per-recv timeout, remaining budget)`, so a slow-drip attacker
can hold a connection open at most 10 s regardless of how many tiny
fragments it sends.

New constant in `src/include/hix_const.ch`:
```
#define HIX_HEADER_TOTAL_TIMEOUT  10000   // 10 s total header read budget
```

### A1.23 — Body 413 Payload Too Large (`src/hix_router.prg`)

`HIX_RouteDispatch()` now checks `Content-Length` against the existing
`HIX_MAX_BODY_SIZE` constant before entering the route loop. If the
declared body exceeds the limit the connection is closed (keep-alive
disabled) and a `413 Payload Too Large` JSON response is returned
immediately — no body bytes are read at all.

### A1.24 — JSON recursion depth guard (`src/hix_request.prg`)

`JsonBody()` runs `_HixJsonMaxDepth()` before calling
`hb_jsonDecode()`. The scanner walks the raw JSON string in O(n)
time counting bracket/brace depth while correctly skipping characters
inside quoted strings (including `\"` escapes). If depth exceeds
`HIX_MAX_JSON_DEPTH` (64) the decode is skipped and an empty hash is
returned, preventing a stack-overflow DoS from deeply nested input.

New constant in `src/include/hix_const.ch`:
```
#define HIX_MAX_JSON_DEPTH  64   // max nesting before refusing decode
```

### A1.25 — Router regex: escape literal path metacharacters (`src/hix_router.prg`)

`_HixPatternToRegexp()` now wraps each literal path character that is
also a PCRE metacharacter (`. + ? ( ) $ |`) in a character class
(`[.]`, `[+]`, etc.). A route declared as `/v1.0/data` no longer
accidentally matches `/v1X0/data`.

### A1.27 — View transpiler: replace `&()` macro-eval (`src/hix_view_transpile.prg`)

`TranspileValidExpression()` replaced the `&('{|| …}')` eval trick
with `hb_CompileFromBuf()`, which compiles a small wrapper function
containing the expression **without executing it**. A malicious
`{{ 1} + Exec() }}` expression is now a compile-time syntax error
rather than executed code in the transpiler thread.

### A1.28 — `UHtmlEncode` robustness (`src/hix_error.prg`)

`UHtmlEncode()` adds a type-safety guard: non-string arguments
(numbers, arrays, NIL) are converted via `hb_ValToStr` before
encoding instead of triggering a runtime type error. The raw-output
`{!! expr !!}` construct in views remains intentionally unescaped by
design.
