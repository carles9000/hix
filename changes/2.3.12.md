# HIX v2.3.12

**Date:** 2026-10-12
**Base:** v2.3.11 (examples/wdo split per driver)

## What was achieved

Nuevo subsistema **HIX_Compile*** incorporado a la lib — bridge nativo
al compilador Harbour + runner HRB con captura de errores robusta.
Contrato unificado "nunca propaga Break": `HIX_CompileCode`,
`HIX_CompileRunPrg` y `HIX_CompileRunHrb` devuelven siempre un hash
con la misma forma, `err` normalizado y `phase` ("compile" / "runtime"
/ "validate"). Suite dogfooded de **45/45 PASS** (los tests se cargan
vía `HIX_CompileRunPrg` desde un harness mínimo).

## Nueva API expuesta

| Función | Propósito |
|---------|-----------|
| `HIX_CompileCode( cSource [, hOpts] [, cFilename] )` | Compila fuente en memoria → `{ ok, hrb, diagnostics, warnings, phase, err }` |
| `HIX_CompileRunPrg( cPath [, ...args] )` | Compila `.prg` desde disco + ejecuta + captura runtime errors en `err` |
| `HIX_CompileRunHrb( cHrbBytes [, cVirtualName, ...args] )` | Ejecuta HRB con `HB_HRB_BIND_FORCELOCAL` → `{ ok, phase, value, err, cleanupError }`. **Nunca re-raise** |
| `HIX_CompileLastError()` | Snapshot runtime del último error (hash con `stack`, `aStack`, `where`, `subsystem`, `genCode`, `subCode`, `description`, `args`) — `THREAD STATIC` |
| `HIX_CompileNormalizeErr( hRaw, lRuntime )` | Normaliza snapshot o diagnóstico raw al shape canónico `err` |
| `HIX_CompileFromBuf( ... )` | Low-level buffer compile (legacy, uso interno) |

### Shape de `err` normalizado

Compile: `{ kind, severity, code, description, file, line, lineCode }`
Runtime: añade `operation, args, subsystem, genCode, subCode, osCode, filename, stack, aStack`.

Warnings no flipean `ok`: `h["ok"]` sigue `.T.`, `err` queda NIL,
`diagnostics` acumula las W-level.

Fuentes nuevas en `src/compile/`:

- `compex.c` — bridge C al compilador Harbour (hb_compMain + buffer)
- `exrun.prg` — runner HRB + wrapper never-break con `BEGIN SEQUENCE WITH` capture callback y fallback para `Break(<non-Error>)`
- `frombufex.prg` — wrapper sobre la C function con shape de hash + synthetic filename (`<caller>-inline.prg`) cuando no se pasa fichero

## Preamble público

`_HixPreamble` promovido a `HIX_Preamble()` + `HIX_PreambleLines()` —
necesario para que `HIX_CompileCode` compense el offset de líneas y
los diagnósticos apunten al código del usuario, no al preamble
sintético.

### Reporting enriquecido

Cada PASS/FAIL que incluye `err` muestra: severity, description,
error code, filename (basename), line, lineCode, y stack cuando hay
2+ frames. `err` puede ser hash único o array de hashes — útil para
tests con múltiples warnings (A08). Frames del stack reducidos a
basename:line proc.

## Comportamiento documentado — D05

`Break( <non-Error> )` desde dentro de un HRB **no** activa el
`WITH-block` del `BEGIN SEQUENCE` capture callback — Harbour
short-circuitea el valor directo al `RECOVER` más cercano. En v2.3.12
el RECOVER captura `ePrimary` manualmente via
`_HixCompileCaptureBreakNoReraise` cuando el WITH-block no corrió, de
modo que `err["description"]` contiene el valor crudo pasado a `Break`.
