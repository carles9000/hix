# HIX v2.4.6

**Date:** 2026-11-04
**Base:** v2.4.5
**Type:** Feature

## What was achieved

Nueva API `POST /hix-setup-api` para bootstrap programático de las
credenciales admin: acepta body JSON o form-urlencoded, responde
siempre JSON (201/409/422) y escribe `user`, `secret` y `password`
(HMAC-SHA256) en `hix.json` cuando el panel aún no está configurado.

### Endpoint

```
POST /hix-setup-api
Content-Type: application/json
{ "user": "admin", "password": "secreto123" }
```

| Caso                              | Status | Body JSON                                   |
|-----------------------------------|--------|---------------------------------------------|
| Credenciales vacías → OK          | 201    | `{ "ok": true, "user": "<user>" }`          |
| Admin ya configurado              | 409    | `{ "ok": false, "error": "already_configured" }` |
| `user` vacío                      | 422    | `{ "ok": false, "error": "user_empty" }`    |
| `password` con menos de 6 chars   | 422    | `{ "ok": false, "error": "password_short" }`|

- Solo activo mientras `admin.user` / `admin.password` están vacíos:
  una vez el panel tiene credenciales, el endpoint responde 409 y no
  permite reset (misma política que `/hix-setup`).
- Acepta JSON (`Content-Type: application/json`) y, como fallback,
  `application/x-www-form-urlencoded`.
- El hash guardado es `lower(HMAC_SHA256(password, secret))`; el
  `secret` se genera en el momento (`HMAC_SHA256(timestamp+user, password)`).

### Refactor compartido

Se extrae `_HixAdminSetupApply( cUser, cPass, @cErr )` como helper
interno de `hix_admin.prg`. Lo usan tanto `HIX_AdminSetupPost` (form
HTML) como el nuevo `HIX_AdminSetupApi` (JSON). Mismos códigos de
error en el canal interno (`user_empty`, `password_short`,
`already_configured`); cada endpoint traduce al formato que le toca.

### Tests

Nuevo test `tests/unit/src/hix_test_admin_setup_api.prg` con 7
casos: constante de ruta, success JSON, success form-urlencoded,
409 already configured, 422 user empty, 422 password short y
verificación del HMAC-SHA256 contra `hCfg[admin][secret]`. 17
assertions, todas en verde.
