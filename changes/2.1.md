# HIX v2.1

**Date:** 2026-09-07
**Release commit:** `69168fe` — release: v2.1

## What was achieved

HIX becomes **cross-platform**. The same library, the same examples and
the same test suite compile and run on **Windows (MSVC / MinGW64)**
and on **Linux (gcc)**, with **1668/1668 tests green** in both environments.

Before 2.1, HIX was Windows-only. This release closes the migration to
Linux by working on four fronts in parallel: library, tests, examples and
build scripts.

## Changes by area

### 1. Library (`src/hix_server.lib` / `libhix_server.a`)

- **`feat(build)`** `2ea1f03` — the lib compiles on Linux/gcc in addition to Windows/MSVC.
- **`build(lib)`** `9c5a4af` — each toolchain (MSVC / MinGW64 / gcc) produces its
  own isolated folder + preflight checks to avoid mixing outputs.
- **`build(linux)`** — `go_lib.sh` as the Linux equivalent of `go_lib_msvc.bat`.
- Critical fix in the .hbp: `{unix}${hb_inc}/harbour.hbx` so that
  `--gc-sections` does not drop symbols only used by the .hrb (memory saved
  as a persistent rule).

### 2. Tests (`tests/unit/`)

- **`2bb5357`** — `tests/unit/app.hbp` becomes cross-platform, with extended
  stubs for symbols that differ between platforms.
- **`379846f`** — the **last 6 failures** on Linux are hunted down. Final
  status: **1668 / 1668 green** on Windows and on Linux.
- **`ff732e5`** — Linux-specific fixes for the test dashboard:
  path separators, keep-alive body drain, host allowlist.
- **`f2b19e2`** — the dashboard now shows an **OS badge + compiler version**
  in the nav, so it's obvious which toolchain the tests you're looking at
  are running on.
- **`44f0c77`** — the `/test` suite is served as a declarative route from
  the `examples/api` example.

### 3. Examples (`examples/`)

- **`32320d6`** — cross-platform examples: each example now carries three
  homogeneous scripts:
  - `go_gcc.sh`      — Linux
  - `go_mingw64.bat` — Windows / MinGW64
  - `go_msvc64.bat`  — Windows / MSVC
- **`b92db58`** — the `web` examples (crud, hi) align their build scripts
  with the one from `examples/server` so all of them follow the same template.
- Simplification of `app.prg` in the examples; removal of the obsolete
  `appconfig`/`appmiddleware`.
- Drop of the legacy `install/go_nic.bat`; refresh of `hix_setup.exe`.

### 4. Responsive shutdown

Problem found during Linux validation: the server did not close cleanly
because the keep-alive loop and `hb_idleSleep` were blocking shutdown.

- **`b75aa87`** — the keep-alive loop breaks when it detects `server stop`.
- **`32320d6`** (part) — responsive shutdown on Linux.
- Persistent memory: `hb_idleSleep(N)` is uninterruptible → threads that
  need to react to shutdown must use `hb_mutexSubscribe` or sleep in
  short slices.

### 5. Housekeeping and build

- **`510ad4f`** — `.gitignore` for Linux build artifacts + WSL2 validation
  plan.
- **`9155d5d`** — A/B load tester + CORS on `/hix-ping` (useful to compare
  performance across platforms).
- **`7687d64`** — pruning of compiled binaries and legacy docs; the
  `ucurl` module is added.
- **`650a3bd`** — new refined `go_lib.sh`.

## Impact

- New officially supported platform: **Linux (gcc)**, validated on WSL2.
- `HIX_VERSION_SERVER` bumps to **2.1** (updated in `hix_server.prg`,
  `hix.iss`, `whatsnew.txt`).
- Windows compatibility intact: MSVC and MinGW64 keep working without
  changes to user code.
- Derived projects only need to copy the trio of scripts
  (`go_gcc.sh` / `go_mingw64.bat` / `go_msvc64.bat`) from `examples/` to
  gain multi-platform support.
