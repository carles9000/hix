# HIX v2.1

**Fecha:** 2026-09-07
**Commit de release:** `69168fe` — release: v2.1

## Qué se ha conseguido

HIX pasa a ser **cross-platform**. La misma librería, los mismos ejemplos y
la misma suite de tests compilan y funcionan en **Windows (MSVC / MinGW64)**
y en **Linux (gcc)**, con **1668/1668 tests en verde** en ambos entornos.

Antes de la 2.1 HIX era Windows-only. Esta release cierra la migración a
Linux tocando cuatro frentes en paralelo: librería, tests, ejemplos y build
scripts.

## Cambios por área

### 1. Librería (`src/hix_server.lib` / `libhix_server.a`)

- **`feat(build)`** `2ea1f03` — la lib compila en Linux/gcc además de Windows/MSVC.
- **`build(lib)`** `9c5a4af` — cada toolchain (MSVC / MinGW64 / gcc) genera su
  propia carpeta aislada + preflight checks para evitar mezclas.
- **`build(linux)`** — `go_lib.sh` como equivalente Linux de `go_lib_msvc.bat`.
- Fix crítico en el .hbp: `{unix}${hb_inc}/harbour.hbx` para que
  `--gc-sections` no tire símbolos que solo usa el .hrb (memoria guardada
  como regla persistente).

### 2. Tests (`tests/unit/`)

- **`2bb5357`** — `tests/unit/app.hbp` pasa a cross-platform, con stubs
  extendidos para los símbolos que difieren entre plataformas.
- **`379846f`** — se cazan los **6 últimos fallos** en Linux. Estado final:
  **1668 / 1668 verdes** en Windows y en Linux.
- **`ff732e5`** — fixes específicos del dashboard de tests en Linux:
  separadores de path, drenaje del body en keep-alive, allowlist de host.
- **`f2b19e2`** — el dashboard muestra ahora un **badge de SO + versión del
  compilador** en la nav, para que sea evidente en qué toolchain corren los
  tests que estás mirando.
- **`44f0c77`** — la suite `/test` se sirve como ruta declarativa desde el
  ejemplo `examples/api`.

### 3. Ejemplos (`examples/`)

- **`32320d6`** — ejemplos cross-platform: cada ejemplo lleva ahora tres
  scripts homogéneos:
  - `go_gcc.sh`      — Linux
  - `go_mingw64.bat` — Windows / MinGW64
  - `go_msvc64.bat`  — Windows / MSVC
- **`b92db58`** — los ejemplos `web` (crud, hi) alinean sus build scripts
  con el de `examples/server` para que todos sigan la misma plantilla.
- Simplificación de `app.prg` en los ejemplos; eliminados los obsoletos
  `appconfig`/`appmiddleware`.
- Drop de `install/go_nic.bat` legacy; refresh de `hix_setup.exe`.

### 4. Shutdown responsive

Problema encontrado durante la validación en Linux: el servidor no cerraba
limpiamente porque el loop de keep-alive y `hb_idleSleep` bloqueaban el
shutdown.

- **`b75aa87`** — el loop de keep-alive rompe al detectar `server stop`.
- **`32320d6`** (parte) — shutdown responsive en Linux.
- Memoria persistente: `hb_idleSleep(N)` es ininterrumpible → los threads
  que necesiten reaccionar al shutdown deben usar `hb_mutexSubscribe` o
  dormir en tramos cortos.

### 5. Housekeeping y build

- **`510ad4f`** — `.gitignore` para artefactos de build de Linux + plan de
  validación WSL2.
- **`9155d5d`** — A/B load tester + CORS en `/hix-ping` (útil para comparar
  rendimiento entre plataformas).
- **`7687d64`** — poda de binarios compilados y docs legacy; se añade el
  módulo `ucurl`.
- **`650a3bd`** — nuevo `go_lib.sh` refinado.

## Impacto

- Nueva plataforma soportada oficialmente: **Linux (gcc)**, validada en WSL2.
- `HIX_VERSION_SERVER` sube a **2.1** (actualizado en `hix_server.prg`,
  `hix.iss`, `whatsnew.txt`).
- Compatibilidad Windows intacta: MSVC y MinGW64 siguen funcionando sin
  cambios en el código del usuario.
- Los proyectos derivados solo tienen que copiar el trío de scripts
  (`go_gcc.sh` / `go_mingw64.bat` / `go_msvc64.bat`) desde `examples/` para
  ganar soporte multiplataforma.
