# HIX v2.3.06

**Date:** 2026-10-02
**Base:** v2.3.05 (WDO MySql per-thread init guard)

## What was achieved

Cierre del ciclo WDO MySQL: ejemplos y documentación completos y listos
para producción.

- **`dbharbour` eliminado** — todos los ejemplos y docs migrados a la base
  de datos estándar `employees` (datacharmer/test_db). Afecta:
  `examples/wdo/www/config.json`, `mysql1.html`, `mysql2.html`,
  `mysql_prep_bind.html`, `tests/wdo/test_wdo_mysql.prg`,
  `docs/mysql/`, `site-docs/es/wdo/mysql/`.

- **Ejemplos WDO adaptados a `employees`** — `mysql2.html` y
  `mysql_prep_bind.html` usan ahora la tabla `employees`
  (`emp_no`, `first_name`, `last_name`, `gender`, `hire_date`).
  `mysql_prep_loop` y `mysql_trans` usan tablas temporales propias
  (sin cambios).

- **`HIX_InitPoolsFromConfig` default `lAbortOnFail = .T.`** — el pool
  aborta el arranque si falla. Antes requería pasar `.T.` explícito.

- **DLL error simplificado** — mensaje reducido a
  `==> Error: Cannot load MySQL DLL` + `Press any key to continue...`.

- **Site-docs WDO MySQL** — sección completa en ES / EN / IT:
  7 páginas por idioma (Concepto y Pool, Instalación, Configuración,
  Uso del pool, Prepared Statements, Transacciones, Troubleshooting).
