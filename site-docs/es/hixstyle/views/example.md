## 📖 Introducción a los ejemplos

Para poder ejecutar los siguientes ejemplo directamente desde la url del 
navegador, recuerda tener el parámetro de hix.json `app.dispatch_mode = "full"`. 

Esto permitirá ejecutar ejecutar directamente desde la url los ejemplos 
en prg que especifiquemos: 

`http://localhost/controllers/example4.prg`

Recuerda que una de las características de usar HixStyle es poder gestionar 
diversos de seguridad y el uso director de ficheros .prg/.hrb deberia 
estar bloqueado por temas de seguridad.
