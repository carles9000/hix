## 📖 Introduction to Examples

To run the following examples directly from your browser's URL, remember to set the `app.dispatch_mode = "full"` parameter in hix.json. 

This allows you to run the PRG examples directly from the URL:

`http://localhost/controllers/example4.prg`

Remember that one of the characteristics of using HixStyle is managing various security aspects, and direct access to .prg/.hrb files should be blocked for security reasons.
