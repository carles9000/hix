## 📖 Introduzione agli esempi

Per eseguire i seguenti esempi direttamente dall'URL del browser, ricordati di impostare il parametro `app.dispatch_mode = "full"` in hix.json.

Questo ti permette di eseguire gli esempi PRG direttamente dall'URL:

`http://localhost/controllers/example4.prg`

Ricorda che una delle caratteristiche dell'uso di HixStyle è la gestione di vari aspetti di sicurezza, e l'accesso diretto ai file .prg/.hrb dovrebbe essere bloccato per motivi di sicurezza.
